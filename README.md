Simply double-click or open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).
- **File location**: `C:\Users\Admin\Documents\projects\portfolio\index.html`

### Option 2: Run with Vite & React Development Server
If you'd like to use the React development workflow:
1. Open PowerShell or Terminal in this folder:
   ```bash
   cd C:\Users\Admin\Documents\projects\portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Open the local link (e.g. `http://localhost:3000`) in your browser.
